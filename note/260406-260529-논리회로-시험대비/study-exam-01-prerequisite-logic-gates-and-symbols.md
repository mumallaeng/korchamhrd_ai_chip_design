## 한 줄 정의

`논리회로`는 전압을 `0/1`로 추상화해서 계산하는 체계다.

## 1단계 핵심 개념

| 개념 | 의미 |
| --- | --- |
| `전압` | 실제 물리 신호 |
| `0/1` | 전압을 단순화한 논리값 |
| `bit` | `0` 또는 `1` 하나 |
| `입력/출력` | 회로 데이터 흐름 |
| `진리표` | 입력마다 출력이 어떻게 되는지 정리한 표 |

## 전압과 논리값

- 실제 회로에는 연속적인 전압이 존재한다
- 디지털 회로는 그것을 `0`과 `1`로 단순화해서 본다

| 실제 전압 예 | 논리값 |
| --- | --- |
| `0V` 근처 | `0` |
| `3.3V` 또는 `5V` 근처 | `1` |

## bit

`bit`는 `0` 또는 `1` 하나다.

| Binary | Decimal |
| --- | --- |
| `0000` | `0` |
| `0001` | `1` |
| `0010` | `2` |
| `0011` | `3` |

## 왜 2진수를 쓰나

트랜지스터는 `ON/OFF` 두 상태로 다루기 쉽다.

| 트랜지스터 상태 | 논리값 |
| --- | --- |
| `OFF` | `0` |
| `ON` | `1` |

## 입력과 출력

논리회로는 보통 아래 흐름이다.

```text
입력
-> 회로
-> 출력
```

예:
- `A = 1`
- `B = 0`
- 회로가 규칙대로 계산해서 결과 출력

## 진리표

진리표는 입력 조합마다 출력이 어떻게 되는지 적는 표다.

| A | B | 출력 |
| --- | --- | --- |
| `0` | `0` | `?` |
| `0` | `1` | `?` |
| `1` | `0` | `?` |
| `1` | `1` | `?` |

## 다음 단계

이제 다음은 `Logic Gate`다.

1. `NOT`
2. `AND`
3. `OR`
4. `NAND`
5. `XOR`

여기까지 잡히면 `조합논리`, `Adder`, `MUX`가 쉬워진다.

## 한 줄 정리

지금 단계에서 익숙해져야 하는 것은 `전압`, `0/1`, `bit`, `입력/출력`, `진리표`다. 그 다음이 `gate`다.
