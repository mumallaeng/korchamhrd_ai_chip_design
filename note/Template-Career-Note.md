# 26-MM-DD - 핵심 주제 요약 (커리어/채용/멘토링 수업용)

이 파일은 골격 예시다. 실제 노트를 쓸 때는 이 구조를 복사해서 값만 채우고, 이 설명 문단들은 지운다.

## 작성 규칙

- 표 셀 끝에는 `~한다`, `~된다`, `~이다` 같은 완결형 어미를 쓰지 않는다. `~함`, `~확인`, `~결정`, `~기준`처럼 명사형으로 끝내고 마침표를 붙이지 않는다.
- 본문 문장은 서술형(`~한다`, `~된다`)으로 쓴다.
- `녹화`, `녹음`, `전사`, `STT`, `SRT`, `자막` 같은 캡처·처리 과정 단어를 본문에 남기지 않는다.
- 강사 개인 발언(잡담, 진행 안내, 출석 확인)은 옮기지 않는다. 채용·커리어 관점에서 재사용 가능한 개념·기준·전략만 남긴다.
- 기업명·수치 예시(연봉, 채용 인원 등)는 강사가 실제로 언급한 값만 쓰고, 추정치를 새로 만들지 않는다.

## 골격

```markdown
# 26-MM-DD - 핵심 주제 요약

관련 노트:

- [26-MM-DD - 이전 관련 커리어 노트 제목](이전-노트-파일명.md)

## 개념 섹션 제목

개념 설명 본문. 왜 이 기준이 생겼는지 → 무엇을 의미하는지 → 지원자가 어떻게 대응해야 하는지 순서로 쓴다.

| 표 제목 | 설명 |
| :--- | :--- |
| 항목 | 명사형 설명 |

(개념 섹션은 다룬 키워드 수만큼 반복한다. 강의 순서가 아니라 주제 단위로 묶어도 된다.)

## 다음에 할 것

- 다음 액션 1 (예: 이력서 항목별 수치화 정리)
- 다음 액션 2 (예: 지원 기업 핵심 가치 조사)
```
