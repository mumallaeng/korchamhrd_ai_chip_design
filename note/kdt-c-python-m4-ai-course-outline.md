# KDT C/Python/M4/AI 과정 LMS 목차

이 노트는 Korcham 과정에서 사용하는 LMS 목차를 한 번에 훑기 위한 인덱스다. 날짜별 수업메모는 별도 날짜 노트에 두고, 여기서는 단원명, 예제, 자습, 과제 항목을 중복 없이 정리한다.

주의할 점은 LMS의 `C-*` 표기가 C언어가 아니라 Python 단원 그룹에도 사용된다는 점이다. C언어 날짜 노트의 `C Lab`과 혼동하지 않도록, 이 노트에서는 LMS 표기를 그대로 두되 영역을 나누어 본다.

## 전체 흐름

| 영역 | LMS 항목 | 내용 |
| :--- | :--- | :--- |
| 공통 | 오리엔테이션 | 과정 안내, 실습 환경, 평가 방식 |
| C 언어 | `A.C언어 정리`, `B.C언어 확장`, `B. C 과정 평가` | PC GNU C 기초, C 문법 확장, 문자열 함수 평가 |
| Python | `C-1`~`C-10`, `C. Python 과정 평가` | Python 기본 문법, container, 함수, comprehension, 제어문 |
| M4/Embedded | `D-5`~`D-12` | STM32 GPIO, UART, Timer/PWM, Interrupt |
| AI | `E-1`, `E-2` | Deep Learning, Raspberry Pi On-Device AI |

| 단원 | LMS 항목 | 핵심 |
| :--- | :--- | :--- |

| `D-12` | Interrupt 제어 | KEY IRQ, USART2 event IRQ, timer event IRQ |
