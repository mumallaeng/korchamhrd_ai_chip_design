*[컨소시엄] 온디바이스AI 시스템반도체 설계 2기* 교육과정의 Classroom 제출물을 정리할 때 쓰는 도구입니다.

## 도구

- `deliverable-share/`: 반 전체 제출물 관리
  - Drive 동기화 폴더의 제출물 스캔
  - macOS·Windows 간 한글 파일명 정규화
  - 필수 산출물 검사
  - 학생별 제출 폴더 Drive 공유
  - Classroom 비공개 댓글용 copybook 생성

- `project-packager/`: 개인 프로젝트 제출 폴더 구성
  - 발표자료·영상·소스 복사
  - 완료보고서·일정표·일지 생성
  - 제출 폴더명·파일명 규칙 적용
