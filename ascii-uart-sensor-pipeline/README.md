# ascii-uart-sensor-pipeline

`260421`~`260430` UART/FIFO 수업 기간에 진행한 Basys 3 대상 UART 센서 파이프라인 프로젝트입니다. `mini_project-UART_FIFO`가 이 저장소 안에 커밋 원본을 보존한 초기 결과물이라면, 이 프로젝트는 그 결과물을 정리해 별도 저장소로 옮긴 후속 버전입니다.

관련 수업 노트: [260430 FIFO 센서 인터페이스](../note/260430-fifo-sensor-interface.md), [260429 시프트 레지스터 RX FIFO](../note/260429-shift-register-rx-fifo.md)

구현 저장소: <https://github.com/mumallaeng/ascii-uart-sensor-pipeline>
